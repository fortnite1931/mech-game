КОД:
  assets.ts  — mech_robot + mech_industrial (GLB + клипы)
  mechRig.ts — MECH_DEFAULTS для обоих, spec robot/industrial
  panels.ts — 'animations'
  animationsPanel.tsx — редактор анимаций (таймлайн, нарезка, скорость, настройки)
  inspector.tsx — роли: игрок / резерв / враг / спавн / декорация
  mechPanel.tsx — подсказка + кнопки ролей + синхронизация с движком
  hud.tsx — подсказка ближайшего меха + броня
  EditorEngine.ts — анимация по движению, мульти-выделение, рамка, расстояние входа,
                  восстановление после превью, запуск пилота, профиль FPS
  PlayController.ts — animState (состояния: idle/walk/run/jump/damaged/critical),
                      damageMech (урон по броне меха), enterMech с дистанцией,
                      F с дистанцией, idleSway в покое
  playTypes.ts — CHASSIS для robot/industrial, MechConfig (animSpeed, enterRange, idleSway)
  idleSway.ts  — механическое покачивание корпуса
  pilotModel.ts — GLB пилот + шейдерная ходьба/бег
  effects.ts  — пулы частиц, обломков, декалей (1 draw call вместо 40)
  worldChunks.ts — буферы не пересоздаются, ограничение продвижения пропов (3/кадр)
  game/project.ts — нормализация ролей (player/reserve/enemy/spawn/neutral)
  game/objectRole.ts — листовой модуль ролей
  game/playerKit.ts — без TS-параметра (Node)
  App.tsx — вкладка «Анимации», мульти-выделение (Ctrl+рамка, Ctrl+клик)
  workspace.tsx — иконка animations

ИСПРАВЛЕНИЯ:
  — пропы больше не «вырастают» из-под земли (Y не трогаем, только масштаб)
  — радиус мира = авто от видимости (туман с запасом 60%), не стационарный 4
  — общие материалы не освобождаются при удалении пропа (без перекомпиляции шейдеров)
  — фризы при подъёме пропов ушли (кэш геометрии, ограничение на 3 пропа/цикл)
  — перезапуск превью (стоп) — лёгкое восстановление (без пересборки геометрии)
  — ролей больше не теряются при сохранении и загрузке проекта
  — профайлер: сырое время кадра, фоновые вкладки фильтруются, разбор по фазам
  — сервер журнала: NDJSON, автоматическая сессия, ручная выгрузка
  — игра: анимация ходьбы/бега подстраивается под скорость, урон по меху,
               дистанция посадки, баг с KeyH (аптечка/H) исправлен
  — промышленный мех добавлен в библиотеку
