# AGENTS.md — инструкция для ИИ-агентов и разработчиков

Этот файл — главная память проекта. Читай его ПЕРВЫМ, затем уже код.
Он обновляется по мере развития. Если планируешь большие изменения — дополни этот файл.

## Проект

Постапокалиптический игровой движок + редактор (Three.js/WebGL/TypeScript).
- `src/editor/` — редактор (панели, инспектор). НЕ попадает в релиз игры.
- `src/game/` — игровой клиент: меню, уровни, состояние, экраны. Растёт.
- `src/three/` — общий движок: рендер, мир, контроллеры, генерация, анимации.
- `src/components/` — UI-компоненты редактора (React).
- `tests/` — юнит-тесты (node:test).
- `public/library/` — рантайм-ассеты (GLB-модели: мехи, пилот, анимации).
- `Сцены/` — исходные авторские файлы сцен (JSON/GLB), НЕ используются рантаймом напрямую.

## Команды

- `npm install` — установить зависимости.
- `npm run dev` — dev-сервер (Vite, обычно порт 5173).
- `npm run build` — сборка. Выход: `dist/`.
- `node --test` — запуск всех тестов (сейчас 92 теста, все должны проходить).
- `npx tsc --noEmit` — проверка типов TypeScript.
- Сборка с ограничением памяти (на слабых машинах): `node --max-old-space-size=6144 node_modules/vite/bin/vite.js build &&или env-переменная).

## Архитектурные соглашения

- Всё ядро — в `src/three/`: `PlayController.ts` (геймплей/превью), `EditorEngine.ts`
  (редакторская сцена), `assets.ts` (реестр ассетов и клипов), `worldGen.ts`,
  `worldChunks.ts` (генерация мира), `pilotModel.ts` (загрузка/клонирование пилота),
  `enemies.ts`, `projectiles.ts`, `fx.ts` (эффекты).
- Игра и редактор — две сборки одного проекта (см. `vite.config.ts`).
  Редактор — история, на GitHub Pages публикуется только ИГРА (корень `src/game/`).
- Ассеты в коде загружаются через относительные пути от корня сборки:
  `import { ASSET_BASE } from '../utils/baseUrl.ts'` → `${ASSET_BASE}library/...`.
  НИКОГДА не используй абсолютные пути вида `/library/...` — сломается на GitHub Pages.
- Пилот (GLB со скелетом) клонируется ТОЛЬКО через SkeletonUtils.clone
  (`import { clone as skeletonClone } from 'three/addons/utils/SkeletonUtils.js'`).
  Обычный `.clone()` рвёт связь SkinnedMesh↔скелет.
- У объектов сцены есть РОЛЬ (`role`) и ТИП (`typeId`). Это разные сущности:
  роль — «кем объект в превью» (player/reserve/enemy/spawn/prop),
  тип — «из какой сборки он сделан» (шасси, оружие, ИИ). См. `src/game/objectRole.ts`.
- Анимации мехов/пилота: состояния → клипы. Назначение клипов — в панели «Анимации»
  (clipMap у объекта). Пилот имеет клипы: Walk, Run_Anime, Climb_Wall, Fixing_Kneeling, Idle_A.
  Zombie_Walk / Zombie_Walk_2 — это анимации «подбитого меха» (состояния damaged/critical).
- «Покой» пилота: играет Idle_A (или заданный вручную клип). См. PlayController.updateFreeCamera.
- Автоподход пилота к меху: расстояние > 2.5 м → подбегает (run/walk), потом вкарабкивание
  (Climb_Wall) с подъёмом вверх. Отмена — WASD.
- Меню/экраны игры — в `src/game/` (стартовое меню, уровни, пауза, рестарт, сохранения).
- Сохранения игры — в localStorage / SDK платформы (Яндекс Игры, VK Play).
