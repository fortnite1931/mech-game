# Wasteland Forge — постапокалиптический редактор и игровой движок

Редактор мира и движок для игры про мехи (WebGL/Three.js/TypeScript). Один проект,
две сущности: **редактор** (конструктор сцен, панели, типы объектов) и **игра**
(публикуемый клиент: меню, уровни, экраны).

## Возможности

- 3D-редактор сцены: объекты, роли, типы, ландшафт, генерация мира.
- Превью игры прямо в редакторе (мехи, пилот, враги, турели, эффекты).
- Пилот с настоящими скелетными анимациями (GLB): ходьба, бег, лазание в мех, покой.
- Генератор мира: ландшафт, чанки, пропы, туман.
- Анимации мехов: Walk/Run, состояния «Ранен»/«На грани» (зомби-клипы для подбитого меха).
- Скрипты/сценарии, звуки, сохранения проектов, профайлер производительности.

## Быстрый старт

```bash
npm install
npm run dev        # dev-сервер (Vite)
npm run build      # сборка в dist/
node --test        # тесты
npx tsc --noEmit  # проверка типов
```

## Где что лежит

- `src/editor/` — редактор (панели, инспектор) — не входит в релиз.
- `src/game/` — игровой клиент: меню, уровни, состояние (растёт).
- `src/three/` — общий движок (PlayController, EditorEngine, генерация мира, анимации).
- `src/components/` — React-компоненты UI редактора.
- `public/library/` — рантайм-ассеты (GLB: мехи, пилот, анимации).
- `tests/` — юнит-тесты (node:test).
- `AGENTS.md` — подробная инструкция для ИИ-агентов и разработчиков (читай первым).
